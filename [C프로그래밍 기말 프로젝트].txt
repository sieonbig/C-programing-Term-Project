[C프로그래밍 기말 프로젝트]

1. 프로젝트 주제 선정 이유
어린 시절 영어학원에서 원어민 선생님과 즐기던 행맨 게임의 추억을 C프로그램으로 구현하기 위해 선정.

2. 관련 연구 / 이론적 배경
난수 생성: 매 게임마다 무작위 단어를 선정하기 위해 표준 라이브러리인 <stdlib.h>의 rand()와 <time.h>의 srand(time(NULL))을 활용한 시드(Seed) 설정 기법 적용.
문자 제어: 대소문자 구분을 없애고 입력된 문자를 판정하기 위해 <ctype.h>의 tolower() 함수 활용.

3. 프로그램 설계 및 전체 흐름 구조

1. 게임 초기화 및 시작
   - 프로그램 실행되면 랜덤 단어 뽑으려고 시드 값 설정하고, 누적 점수랑 성공 횟수 0으로 초기화한 다음에 시작 화면 띄워줌.

2. 라운드 반복 루프
   - 게임 끝나지 않고 계속 이어서 진행되도록 반복문 돌려둠. 
   - 반복문 돌 때마다 라운드 진행 함수 불러와서 새로운 한 판 시작함.

3. 라운드 내부 진행 및 판정 흐름
   - 단어 선정: 미리 준비해 둔 영단어 목록에서 랜덤으로 단어 하나 골라오고 길이 계산함.
   - 상태 관리 및 출력: 알파벳 입력 여부 기록하는 배열 초기화하고, 현재까지 맞춘 글자 상태랑 틀린 횟수에 따른 행맨 그림 화면에 보여줌.
   - 입력 및 검증: 사용자한테 알파벳 입력받아서 소문자로 바꾼 뒤, 올바른 입력인지 그리고 이미 입력했던 글자가 아닌지 체크함.
   - 승패 판정: 
     * 입력한 글자가 단어에 들어있으면 빈칸 다 채워졌는지 검사하고, 다 맞췄으면 라운드 승리로 처리해서 점수 쌓은 다음 다음 라운드로 넘어감.
     * 틀렸으면 오답 횟수 늘리고 행맨 그림 갱신하는데, 기회 다 쓰면 그 라운드는 실패로 처리하고 전체 게임 끝냄.

4. 게임 종료 및 통계 출력
   - 게임에서 실패해서 반복문 끝나면, 그동안 모은 총 성공 횟수랑 누적 점수 최종 통계 화면으로 보여주고 깔끔하게 종료함.

4. 프로그램 구현 내용
- 주요 소스 코드 로직:
  * 중복 입력 및 예외 방어: 사용자가 이미 입력한 알파벳이거나 알파벳 외의 문자를 입력한 경우 예외 메시지를 출력하고 재입력 받음.
  * 승리 판정: 단어 내에 중복 문자가 포함되어 있을 때의 오류를 방지하기 위해, 매 입력마다 전체 단어의 글자가 사용자가 입력한 알파벳 배열에 모두 속해 있는지 순회하며 검사하도록 구현함.

5. 프로그램 동작 결과
1. 게임 시작 화면: 환영 문구와 함께 행맨 타이틀 출력.
2. 라운드 진행:
     +---+
     |      |
            |
            |
            |
            |
   =========

   Word: _ _ _ _ _ _ _ _ _ _ 
   Tries left: 6
   Guess a letter: 
3. 정답/오답 피드백: 올바른 글자를 맞추면 빈칸이 채워지고, 틀리면 행맨 그림이 그려짐.
4. 게임 종료 및 통계: 6번의 기회를 모두 소진하면 게임 오버 메시지와 함께 최종 성공 라운드 수와 총 점수가 출력됨.

6. 결과 분석 및 토의
- 성과: 포인터와 배열을 활용해 문자열을 안전하게 다루는 방법과, 여러 함수 간에 점수나 카운트 변수를 포인터로 공유하여 상태를 유지하는 구조를 성공적으로 구현함.
- 한계점 및 개선 방향: 현재는 소스 코드 내에 고정된 단어 리스트를 사용하고 있지만, 추후 파일 입출력기능을 학습하게 되면 외부 텍스트 파일에서 단어를 불러오거나 역대 최고 점수를 파일로 저장하는 기능을 확장할 수 있을 것임.
