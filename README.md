대구가톨릭대학교 2026학년도 2학기 C프로그래밍 기말 프로젝트입니다.

프로젝트 소개
- **주제:** 행맨(Hangman) 게임 개발 (난이도 下)
- **개발 기간:** 2026년 11월
- **개발자:** [김시언/26120889]

주요 기능
1. 연속 라운드 시스템: 게임이 한 판으로 끝나지 않고, 사용자가 실패할 때까지 자동으로 다음 라운드가 이어짐.
2. 점수 및 통계 출력: 단어 길이와 남은 기회를 바탕으로 점수를 실시간 계산하며, 게임 오버 시 총 성공 횟수와 누적 점수를 최종 통계로 출력함.
3. 입력 확인 및 예외 처리: 알파벳 외의 문자 입력이나 중복 입력에 대한 방어 로직 구현.
